# Selected GStreamer inputs

Decision23 commit `9ad1a52b38cd5028de6b04bcc08192309ef192cf` and PR comment5907711751 authorize this seam. The source files are frozen for independent review. Local fixtures are not model, image, worker or benchmark acceptance.

`materialize_component_authority_v1` and the host CLI in `scripts/publication_gstreamer_component_inputs_v1.py` take these required flags:

```text
--project-root ROOT
--capability-manifest-path ORIGINAL_COMPLETE_TABLE
--calibration-path ORIGINAL_SELECTED_GSTREAMER_CALIBRATION
--model-parity-receipt-path ORIGINAL_ACCEPTED_V4_RECEIPT
--runtime-image-receipt-path FRESH_SELECTED_GSTREAMER_RECEIPT
--worker-freeze-receipt-path ORIGINAL_UNCHANGED_TWO_WORKER_FREEZE
--execution-code-closure-path CURRENT_HOST_CLOSURE
--resource cpu|gpu
--output-dir NEW_PROJECT_NAMESPACE
```

Optional `--container-engine` and `--container-engine-socket` select the actual held executable/socket. URLs, arbitrary model inputs and future guardian sockets are not arguments. Accepted manifest/assessment paths are derived from the original receipt. Original raw numeric acceptance uses that receipt's unchanged aggregate association; its image inspections are routed through the held engine/socket. The actual fresh selected runtime, original unchanged worker recipes/live identities and selected native device probe are verified before authority publication. Source plans are written first; the component authority is the sole final file.

`held_selected_component_inputs_v1(project_root=..., component_authority_path=..., expected_descriptor=...)` holds source material and revalidates the original model evidence/current selected recipes. Its dictionary includes:

- `root`, `document`, `descriptor`, `resource`, `verify_barrier`;
- complete descriptive `capability_manifest`, its descriptor and `candidate_pin`; selected `calibration`, its descriptor and `calib_pin`;
- exact `planned_cells` (two original stock cell dictionaries), decoded `source_plans` keyed baseline/shared;
- `worker_projection` (execution_config/binding_set/workers/runtime_probes), actual eight `worker_capabilities` keyed `(branch, resource)`, bindings/config/probes/preprocessing/parity;
- explicit `execution_code_closure_descriptor`, `policy_request_source_descriptor` and `policy_coordinator_source_descriptor`;
- actual `source_descriptors`, `model_descriptors`, `proxy_model_descriptors`, `image`, `environment`, distinct factual `inventory`, `fixed`, `engine_pin`, `engine_socket`, `capability_hashes`, `probe`, `dataset`, `support_descriptors`.

Physical document descriptors are project-relative. Native capture rows use their exact absolute counterparts. Mount descriptors target `/workspace/project/`. `adapter_descriptor` is `None` until the host caller writes the original adapter asset at the bundle reservation.

The packaged pure `held_component_authority_v1` holds immutable declared bytes/epochs and returns the same source facts without host factory imports. It is used while the guardian/preprocessor/cold join also holds the original operation context. `validate_component_original_native_row_v1(source=..., row=..., source_plan=...)` independently joins selected original coordinates,30/180/10 windows, six streams/four branches, all seven native descriptor roles, the actual stock plan and its derived front workers. The model-authority role is the original accepted receipt, not its binding index.

The original full runtime-input wrappers delegate only their pure pin/device/native constructors. Full qualification/publication predicates remain strict. The complete historical table grants no sibling live capability; component flags remain false for accepted/publication/qualification. Native3/worker2 contexts are still byte-identical to the original freeze; actual live identity remains required. All four shared runtime source identities are invalidated, and selected Gst needs its own refreshed acceptance after reviewed packaging.
