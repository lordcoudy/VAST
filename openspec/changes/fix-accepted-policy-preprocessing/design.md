## Decisions

### 1. Share the reviewed pilot validator without packaging the whole promotion CLI

Extract F5 unchanged into a shared pilot-validation leaf module. Also extract the existing read-only transaction descriptor/cold checks and fragment authority validation into read-only leaf modules. Promotion and the original transaction/fragment builders import/re-export the corresponding leaf validators; guardian imports only the leaves. Leaves own shared exception classes, default dependency dataclasses/functions and the transaction custody ContextVar; builders re-export the same objects, never parallel equivalent definitions. The pilot copy retains its exact stock-copy diff and stock-file hash lock.

Independent read-only AST analysis found that importing either current transaction or fragment builder adds the same 16 project modules missing from every runtime allowlist. Function-body imports are scanned even when the consumer calls only a reader: transaction `_default_validate_complete` imports the pilot executor, and fragment `_rename_directory_noreplace` does likewise. Lazy imports do not resolve the graph. The extracted transaction reader reaches about 14 local functions/250 lines; the fragment reader about 33/937 lines. The supported minimal new project dependency is the leaf module set plus `analytics_execution_capability.py`; other existing dependencies are already in the 63-module guardian closure. Retain the full exact graph/path inventory as implementation evidence before building.

No leaf may import either original transaction/fragment builder, F1, index/bootstrap builder, pilot executor, backend execution/finalizer, guardian or sidecar. Original builders can call leaves in the other direction. Verify standalone leaf imports and both promotion-first and sidecar-first orders in fresh isolated interpreters without preloaded-module caches. Compare pre/post-extraction cold outputs and refusal predicates for mutation, canonical bytes, link rejection, physical custody and default dependency injection. All four allowlists/COPY groups must include each actual leaf/transitive dependency; the original legacy stock policy file stays byte-identical.

Alternative considered: import F1 wholesale into guardian. Rejected because it drags host-only resource/index machinery into packaged runtime and violates the reviewed separation. Changing the stock default pilot validator globally is also rejected because legacy behavior must remain stable.
