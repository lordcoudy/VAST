## Goals / Non-Goals

### Goals

Оценивается whole-system effect выбранной baseline/shared topology на шести logical streams с четырьмя ветвями `vehicle_type`, `damage`, `plate_number`, `foreign_object` (actual selected authority: `publication_gstreamer_component_authority_v1.py:32`). Две исходные recordings повторяются по фиксированному stream mapping; stream replicates не являются независимыми scenes. CPU означает OpenVINO analytics, GPU — TensorRT analytics; hardware decode и общий prefix учитываются как фактические элементы обеих систем. Proxy models/objects не используются как detector-accuracy результат.

Основные результаты: denominator-aware on-time yield при 100 ms, фактические потери и lateness, completed latency distribution, same-domain wait distributions и descriptive paired differences. Не устанавливаются pure service time, kernel time, utilization/energy, обычная camera cadence или population-level significance. Два repetitions дают наблюдённые paired effects/ranges, а не powered inferential study.

Canonical contract прямо снимает 32/Q4/5600 как completion prerequisite новой цели, сохраняя исторические unexecuted/false/zero и strict legacy validators. Это отдельное нормативное решение данного planning change до кода; оно не ретроактивно меняет прежние receipts. Main spec уже разделяет selected component и conditional full-entrypoints (`openspec/specs/benchmark-launch-preparation/spec.md:5–22`).

### Non-Goals

Не исполняются и не ослабляются legacy32/Q4/5600 full campaigns; study не получает full qualification/promotion/publication authority. Не расширяются scenes/model-accuracy, ordinary-camera capacity, kernel/utilization/energy или causal decoder claims. Не создаётся новая publication/observer hierarchy; три узких модуля используют действующие material/executor/custody/cold seams. Planning не запускает tools/media/engine/benchmark и не считается source или hardware acceptance.

### 5. Accounting и результаты

Единица source —`(recording,logical_stream,derived_ordinal,native_PTS,payload_SHA)`; аналитическая opportunity добавляет branch/resource/arm. В measurement denominator включены **все frozen planned opportunities**, включая не offered. Счётчики per stream/branch и общий итог:

- `N_planned = N_not_offered + N_offered`;
- `N_offered = N_not_admitted + N_admitted`;
- `N_admitted = N_delivery_failed + N_delivered`;
- `N_delivered = N_completed + N_controlled_dropped + N_censored + N_failed`.

Здесь admitted —durable original common source/control admission anchor, не более поздняя native consumption и не успешная доставка. Delivered требует actual receive/successful joined transport для всех required recipients: baseline четыре consumers/stream, shared один; queued/fanout enqueue/ACK alone не доказывает delivery. Per-recipient/branch outcomes сохраняются отдельно. Early known admitted key переживает ACK/partial delivery failure и остаётся в raw failed/unknown prefix; такой prefix не является numerical complete/controlled censor. Приведённые partitions —условие целой accepted accounting, не разрешение дописать неизвестный outcome. Frame delivery_failed означает неполную required fanout delivery, а complete требует четыре actual branch terminals. Все множества уникальны/не пересекаются, суммы raw events согласованы с native/guardian outcomes. Infra failure отдельно блокирует accepted arm; запись failure не превращает её в controlled drop. Противоречие/unknown key/duplicate/missing terminal делает scientific reduction failed. Censored требует действительного незавершённого admitted request на frozen drain boundary; не дописывается нулём в descriptive convenience helper. Уже существующий unimplemented cancellation нельзя считать корректным только по формуле.
